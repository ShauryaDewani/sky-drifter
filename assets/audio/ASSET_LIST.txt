                           (Sunny Meadows)           Suggested mood: pastoral, airy.
                                                     Target length: 2–4 min loop.

                                                     Duration: 0.3–0.6 s.
                                                     Always plays (ignores mute flag).

                           level-up overlay shown    Duration: 1–3 s.
                                                     Always plays (ignores mute flag).

AUDIO FORMAT NOTES
=====================================================================
  • MP3 at 128 kbps is sufficient for music; 96 kbps is fine for SFX.
  • OGG Vorbis also works — just rename references in index.html.
  • Keep file sizes small for fast GitHub Pages loading:
      Music  ≤ 5 MB per track
      SFX    ≤ 100 KB each
  • The game uses the HTML5 <audio> element (not A-Frame's positional
    audio component), so no special encoding is required.
  • Browsers require a user gesture before playing audio.
    The game auto-unlocks all tracks on the first touchend event.
