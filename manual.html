SKY DRIFTER

Player Manual & Setup Guide

CMPT 461 · Mobile VR · Trinity Western University

1 · Overview

Sky Drifter is a first-person mobile VR hot-air balloon game built with A-Frame 1.6. Your balloon drifts forward automatically — use your head to steer. Fly through glowing rings and collect orbs to rack up points, and dodge the clouds hiding along the way.

The game spans two hand-crafted levels:

  • Level 1 — Sunny Meadows: open daytime skies, rolling hills, gold rings, and cyan orbs. Advance by clearing 65 % of the rings.
  • Level 2 — Sunset Canyon: warm dusk lighting, towering rock spires, tighter corridors, and a faster balloon. Runs until you exit the canyon (or time out on rings).

Your high score is saved in localStorage and persists between sessions.

A ±7° dead zone around straight-ahead prevents micro-drift. Small movements keep you on course; larger deliberate tilts steer.

3.3 Screen Flow

  1. Flash Screen — Shows game title and student credentials for 5 s.
  2. Settings Screen — Toggle music, adjust sensitivity, view best score.
  3. Level 1 — Sunny Meadows — Clear 65 % of rings to advance.
  4. Level-Up Overlay — 3-second countdown before Level 2 begins.
  5. Level 2 — Sunset Canyon — Fly through to the end of the canyon.
  6. Game Over — Final score, high-score check; play again or back to settings.

5.2 Running Locally

Important
Browsers block local audio/texture loading when you open index.html directly (the file:// protocol). You must serve the folder over HTTP, even locally.

Pick any method below:

  • VS Code + Live Server extension: right-click index.html → Open with Live Server.
  • Python 3: cd sky-drifter && python -m http.server 8080, then open http://localhost:8080.
  • Node.js (npx): npx serve .

5.3 Testing on a Physical Phone (same Wi-Fi)

  1. Start the local server as above. Note your machine's local IP (e.g. 192.168.1.42).
  2. On the phone, open http://192.168.1.42:8080 in Chrome.
  3. Tap the VR goggles icon in the bottom-right corner of the A-Frame canvas to enter Cardboard stereo mode.
  4. Insert phone into headset. Tilt your head to steer!

  3. In the repository, go to Settings → Pages → Source.

  4. Wait ~1 minute. Your game will be live at:
    https://<your-username>.github.io/sky-drifter/
  5. Share the link with anyone — they open it in Chrome on their phone, tap the VR icon, and drop it in a Cardboard headset.
Audio on GitHub Pages
Browsers auto-block audio until the user interacts with the page. The game already handles this: it silently unlocks all audio tracks on the first touch event. No extra configuration needed.

7 · Adding Your Own Assets

Textures

All textures are referenced in index.html inside the <a-assets> block but commented out. Once you have the image files:

  1. Drop them into assets/textures/.
  2. In index.html, find the <!-- TEXTURES --> block and uncomment each <img> tag.
  3. On each geometry element (e.g. <a-sphere>), change the color attribute to material="src: #tex-balloon" (or whichever id).

Recommended free sources (all CC0):

  • Poly Haven — high-quality 1K/2K PBR textures
  • ambientCG — seamless tileable surfaces
  • Kenney.nl — game-ready sprites and panels

Audio

Drop .mp3 files into assets/audio/. The filenames must match exactly what is listed in the <a-assets> block (see assets/audio/ASSET_LIST.txt).

Recommended free sources:

  • Free Music Archive — CC-licensed ambient/chill tracks
  • freesound.org — community SFX library (CC)
  • Zapsplat — professional SFX (free with attribution)
  • OpenGameArt.org — all game-ready, clearly licensed

9 · Known Limitations & Notes

  • iOS Safari: WebXR/Cardboard support requires iOS 15.4+ and the WebXR Viewer app for best results.
  • Audio autoplay: All browsers require a user gesture before playing audio. The game unlocks tracks on first touch automatically.
  • CORS for assets: Textures and audio must be served from the same origin (or with correct CORS headers). Use a local server — never open index.html via file://.
  • Particle system CDN: The trail requires aframe-particle-system-component from unpkg. If that CDN is unavailable offline, the balloon still works — only the trail disappears.
  • Performance: Keep texture sizes ≤ 1024 × 1024 px for smooth 60 fps on mid-range phones.
